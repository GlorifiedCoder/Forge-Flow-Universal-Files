# Package Manifest — Universal Files ZIP

This ZIP includes:

- Universal agent instructions and reusable project workflow.
- Machine A setup, development, test and completion gates.
- Machine B setup, native build, emulator and real-device testing handoff.
- OpenCode independent audit and approved-repair prompts.
- A local ZCode plugin marketplace with reusable skills, slash commands and specialist agents.
- A blank project workspace template containing app-specific planning/documentation placeholders.
- Cross-project Git, testing, security and privacy baseline.
- App Store and Google Play readiness templates with official policy references.
- A PowerShell helper to create a project workspace and copy in separate app inputs.

The separate `ForgeFlow_New_App_Inputs.zip` contains the manual app idea, screens, feature, flow, business-rule, platform, research and asset intake forms.

Intentionally excluded:
- Any app-specific requirements or design choices.
- The manual New App Input forms (provided separately).
- Real credentials and API keys.
- Flutter/Android/iOS SDK binaries.
- Docker images, database server files, or local model weights.
- A promise that generated code is bug-free or will be approved by app stores.
