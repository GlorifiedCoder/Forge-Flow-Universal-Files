# ForgeFlow Local ZCode Marketplace

This directory is a local ZCode marketplace containing one plugin. It uses the documented layout: `marketplace.json`, `.zcode-plugin/plugin.json`, `skills/<name>/SKILL.md`, `commands/*.md`, and `agents/*.md`.

No hooks, shell scripts or MCP servers are included. Skills are working instructions; commands are saved prompts; agents are specialist role prompts. Keep the skills enabled selectively rather than enabling every future skill in every workspace.
