# Blank App Project Template

Duplicate this folder for a specific application. Replace every `[FILL]` or `UNKNOWN` through discovery and approved planning. Preserve the `00_SOURCE_INPUTS/` folder as the original evidence base.

Do not start coding until the agent has produced and reviewed the product brief, requirements, screen inventory, user flows, architecture, risk register and phased plan.


Store-readiness project files include `docs/06_SECURITY_PRIVACY/STORE_COMPLIANCE_IMPLEMENTATION_PLAN.md`, `docs/07_RELEASE/STORE_REQUIREMENTS_MATRIX.md`, `docs/07_RELEASE/STORE_POLICY_SOURCE_LINKS.md`, and `docs/07_RELEASE/STORE_SUBMISSION_EVIDENCE.md`. Complete the policy assessment during discovery; do not defer architecture-sensitive requirements until release.
